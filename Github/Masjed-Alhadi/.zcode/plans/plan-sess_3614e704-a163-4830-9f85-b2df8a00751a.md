## Visual Transformation Plan for Masjed-Alhadi Project

### Phase 1: Asset Audit and Removal
1. Audit all image references in HTML, CSS, and JS files
2. Identify all Basij-Tamin specific assets (basij-logo.svg, decorations, title banners, etc.)
3. Create inventory of assets to be replaced with Islamic mosque theme equivalents

### Phase 2: Visual Design System Establishment
1. Establish Islamic mosque inspired color system:
   - Primary: Deep Emerald Green (#0b3a22 and variants)
   - Secondary: Dark Mosque Green
   - Background: Warm Ivory/Cream
   - Accent: Subtle Islamic Gold (used sparingly)
2. Create CSS design tokens in :root for consistent theming
3. Design clean, minimal aesthetic with Islamic geometric patterns

### Phase 3: Asset Replacement Strategy
1. **Hero/Header Image**: Replace title banner with Islamic architecture image (mosque dome/arch)
2. **Card Icons**: Create 7 SVG icons representing:
   - مسجد (mosque/dome)
   - وجوهات شرعی (coin + crescent)
   - کمک به نیازمندان (helping hands/heart)
   - صدقه اول ماه (moon + hand/coin)
   - نذر نان (bread loaf)
   - قربانی (sheep/sacrifice symbol)
   - نذر عام (gift/donation box)
3. **Background**: Replace busy background with subtle Islamic geometric pattern
4. **Decorations**: Remove Basij-Tamin specific decorations (narges, pigeon) and replace with appropriate Islamic geometric lines or arches if needed
5. **Logo**: Implement text-based logo "مسجد الهادی" with proper typography, reserving space for future logo

### Phase 4: Implementation Details
1. Update HTML files with new asset paths and alt text
2. Modify CSS to use new color variables and design tokens
3. Update JavaScript references to new asset paths
4. Ensure all images are optimized (WebP/AVIF) and locally hosted
5. Add proper alt text for accessibility
6. Maintain responsive design and mobile-first approach

### Phase 5: Validation and Testing
1. Test all pages for visual consistency
2. Verify no Basij-Tamin references remain
3. Check responsiveness across breakpoints
4. Validate accessibility (alt text, ARIA labels, keyboard navigation)
5. Confirm performance isn't degraded by new assets

### Expected Outcome
A visually cohesive Masjed-Alhadi donation portal with:
- Modern Persian Islamic mosque aesthetic
- Clean, trustworthy, spiritual appearance
- Proper asset optimization and licensing
- Full accessibility compliance
- Maintained functionality with updated visual identity
